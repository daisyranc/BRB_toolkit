# 支持范围与已知限制

RIMER支持显式专家规则、AND/OR、数值/类别/信念输入、部分前件、完整/不完整ER、效用区间、DAG信念传播和约束联合训练。R07数值、信念与混合监督目标可配置；训练是局部SLSQP，参考值移动/自动结构搜索不在论文模式内。

MAKER支持全部非空集合焦元、计数/似然证据获取、一般两证据依赖组合、前缀依赖递归、独立/互斥特例及两阶段minimax学习。不同证据顺序需要相应联合/前缀表；单独的两两相关系数不能指定三变量一般联合关系。资源默认上限1023焦元；联合表内存按焦元数平方增长，需控制状态规模。

一般JointEvidence接受显式joint_support；疾病案例的对角分配只由案例的同一观测状态结构确定，不推广成所有数据的自动规则。集合标签和排列必须一致。缺失变量不填补，只有可用子集具有完整联合元数据时才能依赖推理。连续输入离散化由使用者在训练集上确定。

完全可靠、完全互斥的组合需要极限路径；不提供时状态为undefined_limit。无支持结果状态为no_support，不能作普通概率用于继续训练。公开输入严格检查；训练目标有不可定义输入时直接报错，不吞掉错误。

三个demo的验证结论不同：

- BRB：R07建模和约束学习机制可运行，12个训练观测拟合显著改善；不据此证明泛化或精确复现原求解器的全部参数。
- RIMER：R06完整与不完整算例按论文显示精度吻合，包括中间节点及Unknown。
- MAKER：证据表、依赖指数、固定论文参数下Table18概率/可信度吻合；两阶段目标和约束可行。**未完全复现论文报告的训练目标数值**：公开Tables16–17的参数代入正文Eq.86–95，与正文f1=.0075/f2=.0247不一致，差距不能仅解释为四位小数舍入。已核对prior、参考上界和频数因子，仍未解释该差异。解决需要原始补充Excel及其目标/求解配置；本实现未改目标或造结果迎合报告值。

无GUI、自动结构搜索、云服务及其他MAKER应用论文专用模型。不将原Adam训练等同于R07的约束训练。验证范围见[实际记录](validation.md)。
