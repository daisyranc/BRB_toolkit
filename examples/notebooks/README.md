# Paper notebooks

**English** | [简体中文](README.zh-CN.md)

See the [demo guide](../README.md) for setup, execution, references, and reproduction scope.

1. [BRB modelling and training](01_brb_modelling_paper.ipynb): a 39-rule hierarchy and twelve observations.
2. [RIMER inference](02_rimer_inference_paper.ipynb): complete/incomplete inputs and ignorance propagation.
3. [MAKER modelling and training](03_maker_paper.ipynb): dependent diagnosis evidence and two-stage learning.

From the toolkit root, run `python scripts/execute_paper_notebooks.py` to execute all notebooks in fresh kernels and save outputs. Select an environment with `requirements-paper.txt` installed for interactive execution.
